RESEARCH MENTOR FINDER — START HERE

This repository contains the source code for the current Next.js frontend
and FastAPI backend. The main README is the source of truth for setup:

  README.md
  https://github.com/CloudedCoder189/research-mentor-finder#readme

QUICK START (Windows, from the repository root)
1. Install Python 3.12, Node.js 20.9+ and npm.
2. Follow README.md to install backend and frontend dependencies.
3. Seed the included fictional demonstration researchers using the command
   in README.md. The production researcher database is not in GitHub.
4. Start FastAPI on port 8000 and Next.js on port 3000 as shown in README.md.

You do not need an OpenAI API key to try the local keyword-search demo.
Optional features such as semantic search and Google sign-in need separate
configuration. Developer sign-in is disabled unless expressly enabled for
local development.

The legacy Streamlit application (app.py, setup_windows.bat, and
run_windows.bat) remains in the repository for historical compatibility.
Those scripts are NOT the recommended way to start the current website.

PRIVACY
Real .env files, production databases, OAuth tokens, user profiles,
and private outreach data are intentionally excluded from this repository.
Do not commit real credentials or data.
